## Purpose

This folder contains the original comprehensive GuidingDocs that were created as early attempts to keep AI coding models knowledgeable about ZionSync. These documents were extremely detailed (10,287 total lines) and served their purpose well during active development.

## Why Archived

- **Replaced by**: `.github/instructions/zionsync-ai-context.md` (745 lines, more focused)
- **Reason**: GitHub Copilot auto-loads `.github/instructions/` files, making these verbose guides unnecessary for daily AI coding

- **Maintained**: Not deleted - preserved as valuable historical reference
